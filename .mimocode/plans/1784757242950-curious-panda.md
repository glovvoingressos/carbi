# Plano: Auto-preenchimento dos dados extras da placa no anúncio

## Contexto

O usuário quer que ao digitar a placa no início do cadastro do anúncio, TODOS os dados extras da placapi sejam preenchidos automaticamente e exibidos no formulário.

## Análise dos dados

### Dados já preenchidos automaticamente (PlateInput → ListingForm):
| Campo | Campo Form | Fonte API |
|-------|------------|-----------|
| Marca | `brand` | `data.marca` ✅ |
| Modelo | `model` | `data.modelo` ✅ |
| Ano fabricação | `year` | `data.anoFabricacao` ✅ |
| Ano modelo | `yearModel` | `data.anoModelo` ✅ |
| Cor | `color` | `data.cor` ✅ |
| Combustível | `fuel` | `data.combustivel` ✅ |
| Câmbio | `transmission` | `data.cambio` ✅ |
| Tipo veículo | `bodyType` | `data.tipoVeiculo` ✅ |
| Placa | `plateFinal` | `data.placa` ✅ |
| Motor | `engine` | `${data.cilindradas} ${data.potencia}` ✅ |
| Preço FIPE | — | `data.fipe_price` ✅ |
| Mês referência FIPE | — | `data.fipe_reference_month` ✅ |

### O que falta exibir no formulário:
1. **Step 2 (Dados essenciais)**: Campo "Motor" (cilindradas) não está visível
2. **Step 2**: Campo "Placa" não está visível
3. **Step 3 (Confirmação)**: "Motor" e "Placa" não aparecem na revisão
